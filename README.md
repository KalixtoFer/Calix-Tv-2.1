# Calix TV 2.1

App IPTV para **celulares y Android TV**. Acceso con usuario y contraseña al servicio de Calix TV (el servidor ya viene configurado).

- Código de la app: [`android-native/`](android-native/)
- APK: pestaña *Releases* (siempre el último en `releases/latest/download/Calix-TV.apk`)
- Se compila solo con GitHub Actions en cada cambio en `main`
